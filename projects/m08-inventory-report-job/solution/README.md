# M08 reference solution

`solution/src/` replaces `starter/src/`. Only `jobs/report.ts` differs from the
starter; every other file is unchanged.

```bash
cd ../starter
cp ../solution/src/jobs/report.ts src/jobs/report.ts
npm run check:baseline && npm run check:mission
```

Read it only after your own attempt. The header comment explains each change and
is explicit about what the job does and does not guarantee, which is the part
worth arguing with.
